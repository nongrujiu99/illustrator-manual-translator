# 多语言与选中文字框翻译设计

状态：用户已批准。日期：2026-10-26。

## 目的

在现有 Illustrator 说明书翻译面板中选择目标语言，并把“选中文字框后点翻译”作为快捷操作。用户使用选择工具选中一个或多个文字框对象，无需进入文字编辑状态，也无需先扫描全文件。

## 方案与选择

- 方案 A：翻译完直接替换当前选中的文字框。操作最少，但会修改当前文档；使用 Illustrator 的撤销或另存文件回退。用户选择此方案。
- 方案 B：先显示译文预览，再点击应用。更便于校对，但多一次操作；用户没有选择。
- 方案 C：另建工作副本再替换。可保护原稿，但会打断当前选区操作；保留给现有批量流程。

## 行为

1. 面板始终显示目标语言和“翻译所选文字”按钮；默认英语，提供简体中文、繁体中文、日语、韩语、法语、德语、西班牙语、葡萄牙语、俄语。语言选择同时影响批量翻译和手动翻译。
2. 手动按钮读取当前 Illustrator 文档选区，只接受选中的 `TextFrameItem` 对象，不接受文字编辑状态的 `TextRange` 或插入点。支持同时选择多个文字框；混选图形时只翻译文字框，并报告跳过数量。空选区、锁定或隐藏文字框给出明确提示。
3. 手动模式允许任意源语言文本。模型按目标语言翻译，保护型号、数字、单位、已有技术参数与换行。发送当前选中文字，不发送整份文件。取得所有有效译文后才开始回写；请求失败不改文档。
4. 写回当前文档的原文字框，保持对象、位置、颜色、字体和可编辑性；允许小幅缩字适配。译文可能变长，需提示逐项检查版面。手动模式不自动保存文件。
5. 批量模式继续只选中文文字框、写入 AI 工作副本。目标语言由同一选择框控制；译文缓存按目标语言隔离，切换语言后重新进入扫描/翻译步骤，避免把英语译文当成其他语言。输出文件名使用目标语言后缀，如 `_ja.ai`。
6. 阿里云百炼 Key 和高级设置共用；保持“测试连接”“重试、换 Key 后续传”能力。遇到脚本返回错误时显示可读的中文消息。

## 实施约束和验证

- 兼容 Illustrator CC 2019 及更新版本的 CEP/ExtendScript；保持现有批量工作流。
- 用测试验证目标语言进入模型请求、缓存隔离、选中文字框识别、空选区与混选、请求失败无写回、批量文件名。用实际 CC 2019 验证脚本能读取对象选区并回写可编辑文字。
- 手动翻译会直接修改当前打开文件；依赖 Illustrator 撤销与用户保存习惯，不暗中覆盖磁盘上的原文件。
