# Illustrator 翻译插件面板简化设计

## 目标

让用户按当前进度完成“读取文档 → 翻译 → 校对并应用 → 保存”，不必同时理解所有设置和未开始的步骤。仍处理当前文档的所有画板，仅翻译中文，并保留原稿及可编辑文字。

## 面板状态

1. **未读取**：显示当前文档提示和“读取当前文档”主按钮。其他步骤隐藏。
2. **已读取**：显示文档名、画板数、待翻译数、需复核数；“重新读取”为次要按钮。显示阿里云 API Key 与“开始翻译”。服务地域、接口地址、模型名、术语表放入默认收起的“高级设置”。API Key 只在本次面板会话保存。
3. **已翻译**：显示完成条数、默认收起的“查看或修改译文”列表，以及“应用到工作副本”。用户展开后仍能逐条编辑译文；可返回设置并重新翻译尚未手工修改的译文。异常仅在存在时显示计数和可展开详情。翻译失败则保留当前步骤和错误提示，允许重试。
4. **已应用**：显示英语版保存路径与“另存英语版 .ai”。保存结果显示在面板底部。写入失败时显示异常并保持保存按钮不可用。

## 行为与范围

- 继续使用现有扫描、翻译、文本保护、工作副本和另存逻辑；面板只改变信息出现的时机与层级。
- 重新读取文档时清理本轮可见的后续步骤，避免旧译文或旧保存按钮与新文件混用。
- 校对列表只在用户展开时渲染，避免数百个文字框挤满面板。
- 小屏宽度下保持单列，不需要横向滚动。
- 更新使用说明和面板状态测试；验证阿里云默认参数、术语表、人工改译、异常定位、另存路径仍可用。

## 不做的事

- 不改变翻译提示词、文档结构或文本回写算法。
- 不要求用户逐条点击确认译文。
