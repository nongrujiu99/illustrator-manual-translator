# Illustrator 说明书翻译插件：设计方案

状态：待用户批准。日期：2026-10-26。

## 目的

让设计人员在 Illustrator 中打开中文说明书的 `.ai` 或含可编辑文字的 PDF，一次处理当前文件的所有画板，得到英语版 `.ai`。译文应留在原文字区域，图形、图片、图层和画板尽量保持原样，输出文字仍可在 Illustrator 中修改。减少逐个复制翻译和手工排版的时间。

## 已确认的需求与前提

- 输入有 Illustrator `.ai` 和 PDF；现有 PDF 不是扫描件，文字没有转曲。
- 输出统一为 Illustrator 可继续编辑的 `.ai`。
- 首版处理当前打开文件的所有画板，而不是一批独立文件。
- 用户先在 Illustrator 中打开文件，再启动插件；插件只处理当前文档，不要求用户在插件中选择 `.ai` 或 PDF 类型。
- 中文原文由英文译文替换，不做双语并排。
- 已有英文保持原样；首版仅翻译中文内容，空白画板不改动。中英混合的文字框应保护已有英文，无法可靠分离时标记人工处理。
- 允许为容纳英文小幅缩小字号或调整行距；超出允许范围时提示人工处理。
- 用户允许将需翻译的说明书文字发送给外部大模型服务。
- 当前项目文件夹没有样例文件、产品分析或已有代码，也未初始化 Git。因此 PDF 导入效果和实际版式保真度尚未验证。
- 用户确认目标为 Adobe Illustrator CC 2019 或更新版本；CS6 不在首版兼容范围。当前电脑装有 CC 2019，可作为首个验证环境。更新版本需在对应安装环境中做兼容验证。

## 目标、边界与失败标准

### 目标

1. 自动发现所有画板内的可编辑文字，包括组内文字、不同图层和多个画板上的文字；生成翻译前的清单供核对。
2. 对说明书文字进行中文到英文翻译，保持型号、数字、单位、警告级别、符号和占位符；同一术语在文件内保持一致。
3. 将译文写回对应位置，优先保留文字框位置、字体、字色、对齐方式和非文字对象。
4. 对溢出、缺字、缺失字体、无法识别的文字框等问题生成定位清单，方便在 Illustrator 中逐项检查。
5. 保留原文件，另存英语版 `.ai`；提供处理摘要，包括已翻译、跳过和需人工检查的数量。

### 首版不做

- 扫描件 OCR、转曲文字恢复、图片内文字翻译。
- 一次批量处理整个文件夹中的多个文件。
- 保证所有说明书达到像素级零差异。英文长度变化会改变换行，部分页面可能需要人工微调。
- 自动翻译图形中不可编辑的文字，或自动修复任意损坏的 PDF。

### 失败标准

- 静默漏译、截断译文、改动非文字对象、覆盖原文件，或生成无法在 Illustrator 中编辑译文的文件，均视为失败。

## 方案比较与选择

| 方案 | 做法 | 取舍 |
| --- | --- | --- |
| Illustrator 插件面板 + 文档脚本 + 翻译服务 | 在 Illustrator 内操作当前文件，读取和回写文字对象 | **选用。**最符合全部画板处理、原位置修改、导出可编辑 `.ai` 的目标；用户电脑需要安装 Illustrator。 |
| 网页上传 + Adobe Illustrator 云端自定义脚本 | 在云端执行 Illustrator 脚本并下载结果 | 上传体验方便，但相关脚本 API 仍处于公测，首版会增加服务接入与兼容性风险。 |
| 独立 PDF 解析与重新绘制 | 提取文本和坐标后重建页面 | 对原有对象、字体和图层的保真度不够稳妥，不作为首版路线。 |

首版以 CC 2019 为兼容基线，候选实现是 CEP 面板与 ExtendScript 桥接。设计不依赖某一种尚未验证的插件运行时；在更新的 Illustrator 版本上做安装与功能验证，必要时调整面板技术。翻译服务通过可替换接口接入，首版只需接入一个可配置的大模型供应商。

## 用户操作流程

1. 用户先在 Illustrator 打开说明书，再启动插件。若原文件是 PDF，需在 Illustrator 中以可编辑方式导入需要翻译的全部页面；插件直接读取当前文档及全部画板，不出现文件格式选择步骤。
2. 插件预检：统计画板和文字框；列出锁定/隐藏、缺字或缺失字体、画板外对象、链接页面及文字被异常拆分等问题。预检以当前文档的对象状态为准，而非文件扩展名。用户可开始翻译，异常项目保留在清单中。
3. 插件按段落组织文字，连同有限上下文、术语表和不可更改的型号/数字约束发送给模型。用户可在提交前维护术语表。
4. 插件展示原文、译文和位置对应关系；允许修改译文后应用到文档。首版可先提供列表式校对，不要求所见即所得的网页排版编辑器。
5. 应用译文：优先保持原文字框尺寸与位置；必要时在可配置的小幅范围内调整字号或行距。默认建议最大缩字 10%，作为可调整的实施参数，而非已确认的用户要求。
6. 插件检查溢出、字体缺失及未翻译项目，并在 Illustrator 中定位异常文字框。用户确认后另存英语版 `.ai`，原文件不被覆盖。

## 文档处理规则

- 遍历所有画板内的可编辑文字对象，保留文字对象与所属画板的稳定对应关系；画板外、隐藏和锁定对象默认不改动并报告。跨画板对象和串接文字框必须作为异常情形处理，不能重复翻译或静默漏掉。
- 插件仅从 Illustrator 当前文档读取文字对象，`.ai` 与已经打开的 PDF 使用同一套提取、翻译、回写流程。文件来源仅用于诊断和输出命名，不作为用户可见的模式选择。如果当前文档中一段话被切碎为多个文字框，先按位置与阅读顺序恢复逻辑段落，再决定是否可安全写回。无法可靠对应时不自动改动，标记人工处理。
- 译文必须保留技术参数、型号、单位、警示词等级和原文中不可翻译的占位符。翻译请求保留必要上下文；相同术语使用统一词表。模型输出经结构校验后才允许写回。
- 只对中文内容发起翻译；全英文文字框和空白画板跳过。中英混合文字框先将已有英文与技术参数保护为不可改动片段，不能可靠分段时进入人工复核清单。
- 回写时尽量保留原有字形样式与段落样式；混合样式文字要按样式段处理。无法可靠保留局部样式的文字框标记复核，不能静默统一成单一字体。
- 适配顺序：在原框内重排换行 → 小幅调整行距 → 小幅缩字。不得移动非文字元素或随意扩展文字框。仍然溢出时保留完整译文并报错，不能裁掉字符。
- 所有变更在工作副本中完成；保存前形成原文与译文映射和异常报告，以便追查和重复处理。

## 技术组成

1. Illustrator 面板：文件预检、翻译设置、术语表、进度、译文校对、异常定位与另存操作。
2. Illustrator 文档脚本：提取文字对象、样式与几何信息；按对象标识回写；检测溢出；保存 `.ai`。
3. 翻译层：批量分段、上下文管理、术语约束、模型调用、限流重试与结果结构校验。只发送需要翻译的文字及必要上下文，不上传整个原稿；具体供应商由实施时配置。
4. 本地任务数据：记录原文、译文、对象映射、处理状态和错误，支持中断后重新开始或仅重试失败项。

## 验证方式与验收条件

开发前收集至少一份真实 `.ai` 和一份真实 PDF，覆盖多画板、标题、正文、参数表、警告语与混合样式。分别在 Illustrator 中打开后做只读检查，确认当前文档的文字对象结构、字体和阅读顺序；尤其检验 PDF 导入后是否产生异常碎片化或链接页面。如果样例不符合假设，调整统一对象处理流程的异常规则。

首版验收以真实样例为准：所有符合条件的画板文字都出现在清单中；仅中文内容被翻译，已有英文与空白画板保持原样；翻译结果完整且术语可校对；非文字对象没有意外改变；译文在 Illustrator 中仍可作为文字编辑；原文件保留；溢出和无法可靠处理的对象均有可定位报告。视觉比对采用导出预览逐画板检查，异常不被隐藏。

## 留给实施阶段的选择

- 以 CC 2019 为基线验证 CEP 面板、脚本桥接和安装方式，并在可获得的更新版本中做兼容测试。
- 选择首个大模型供应商与密钥管理方式，并给后续切换模型保留接口。
- 根据样例调整默认缩字/行距上限、文字分段规则和 PDF 异常判定。
- 根据样例决定是否需要保存双份交付物（`.ai` 与预览 PDF）；`.ai` 是必须交付物。
