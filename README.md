# Illustrator 说明书翻译插件

适用于 Illustrator CC 2019（23.1.0 已实测）的 CEP 面板。可选目标语言；打开 `.ai` 或可编辑 PDF 后，既可翻译当前选中的文字框，也可批量处理当前文档全部画板。批量模式仅处理含中文的可编辑文字框，译文经校对后写入新的 AI 工作副本，再另存目标语言版 `.ai`。

## 安装

从源码制作 Windows 安装包：运行 `powershell -ExecutionPolicy Bypass -File .\tools\package.ps1`，将生成的 `dist/illustrator-manual-translator-0.1.2-windows.zip` 发给其他电脑，解压后按包内《USAGE.md》安装。`dist/` 是本机生成的产物，不纳入 Git。ZIP 只含运行文件、安装脚本和说明，不含 API Key、渠道预设或样例文档。未签名包需要在目标电脑上为对应 CEP 版本启用无签名扩展加载。

本机开发安装可运行 `powershell -ExecutionPolicy Bypass -File .\tools\install-dev.ps1 -EnableDebug`；已安装后同步源码用 `powershell -ExecutionPolicy Bypass -File .\tools\update-dev.ps1`。重启 Illustrator，在「窗口 → 扩展功能 → 说明书翻译」打开。

## 使用

1. 在 Illustrator 中打开说明书。PDF 要以可编辑方式打开；扫描件、转曲文字、图片内文字不适用。
2. 在面板选择目标语言。提供英语、简体中文、繁体中文、日语、韩语、法语、德语、西班牙语、葡萄牙语和俄语。点击“高级设置”填写 API Key，选择百炼北京、新加坡或自定义 HTTPS Chat Completions 接口及模型，并点击“测试连接”；测试只发送一条短请求，不包含文档内容，可能产生少量 Token 用量。默认使用北京地域的 `qwen-plus`。填写预设名称并点击“保存预设”，即可在下次打开面板时从“已保存的渠道”切换；也可新建、更新或删除预设。保存的 Key 用当前 Windows 账户加密，换电脑或账户需重新输入。未保存的配置只在当前面板会话有效。点击“术语表”可填写术语（每行 `原文=译文`）。点击“文字排版”可选择“保持原字号”或“需要时自动缩小”，设置最多缩小字号 0–30% 和点文字可超出原宽度 0–100%；默认分别为自动缩小、10% 和 10%。这些设置同时适用于手动和批量写入，不会放大字号。三个设置页均可点“返回翻译”回到主页面。百炼接口地域须与 API Key 地域一致；不要把 Coding Plan 专用密钥填入普通百炼地址。正式翻译只发送待翻译文字和术语，不上传整份 AI/PDF。
3. **手动翻译：**用 Illustrator 选择工具选中一个或多个文字框对象，不进入文字编辑状态，点击“翻译所选文字”。翻译完成后直接替换当前文档中的文字，不自动保存；可用 Illustrator 撤销。混选图形时只翻译文字框；模型请求失败时不会改动文档。手动模式可翻译任何源语言。检查版面后自行保存。
4. **批量翻译：**点击“读取当前文档”。面板显示画板数和待翻译数；仅翻译中文，英文和空白画板不进入任务。点击“开始翻译”。每批成功后自动保存进度；临时网络故障、限流及服务端错误最多重试三次。若模型返回多余、缺失或错误的保护标记，插件会拆小该批重新请求，单条仍异常时再重试一次，且不会写入未通过标记校验的译文。中途失败时，可修正接口或更换 Key，点击“继续翻译”，只处理未完成的文字框。关闭面板后重新读取同一文档和目标语言，也会恢复已完成批次。翻译完成后可展开“查看或修改译文”逐条校对。若要调整术语或模型，点击“修改设置并重新翻译”；手工修改过的译文会保留，旧机器译文在对应新批次成功前也不会删除。校对后点击“应用到 AI 工作副本”。译文中已有英文或参数的重复、缺失会列为复核提示，不再逐条阻止写入。插件在系统临时目录新建 `.ai` 后才修改文字。区域文字无法容纳译文，或点文字超过设置的宽度限制时，列为复核项。“需复核”仅在有异常时显示。
5. 检查版面及异常定位，确认自动填写的目标语言版保存路径，再点击“另存翻译版 .ai”。目标已存在时拒绝覆盖。

## 自动处理边界

真正串接的文字、锁定或隐藏内容，以及画板外文字被标记为人工复核，不会静默改写。中英混排中已有英文、型号和数字以占位符保护，模型必须原样返回。版面很密时需要人工调整。当前插件不能保证每个英文段落无溢出，异常报告是保存前检查清单。Illustrator CC 2019 已实测；更新版本仅通过 CEP 版本声明，尚未逐版测试。

本地样例 `F3TEST.ai` 与 `F3TEST.pdf` 均在 CC 2019 中识别为 44 个画板、427 个可编辑文字框，其中 207 个框含中文。修正 Illustrator 自指式 `nextFrame` 判断并加入英文占位符后，这 207 个框都进入了自动翻译清单。实际译文的排版仍需在应用后逐画板检查。样例文件不纳入公开仓库。

## 开发验证

`npm test` 运行分段、占位符、翻译响应和任务恢复测试。`tests/illustrator-fixtures` 中的脚本可在 CC 2019 中生成合成文件并验证另存；测试脚本始终把输出放入项目 `tmp/`，不会改写用户提供的样例。
